## Course frame

Web Page to Web Space asks one central question:

> How does a web-native interaction change when it leaves the browser and enters a room?

Each project should preserve the logic of the web work while transforming at least one of these dimensions:

- Scale: from viewport to architectural proportion
- Input: from mouse/keyboard to body/object/environment
- Feedback: from screen output to light/sound/material behavior
- Audience: from single user to shared public encounter

## Deliverables at a glance
