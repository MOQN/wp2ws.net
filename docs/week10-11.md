#### Bonus

* CommonJS and ES Modules Reference
  * **Built-in modules**
    * CommonJS: `const http = require("node:http");`
    * ES Modules: `import http from "node:http";`
  * **Packages**
    * CommonJS: `const express = require("express");`
    * ES Modules: `import express from "express";`
  * **Local files**
    * CommonJS: `const User = require("./User");`
    * ES Modules: `import User from "./User.js";`
    * Include the file extension in ES Modules.
  * **Export one main value**
    * CommonJS: `module.exports = User;`
    * ES Modules: `export default User;`
  * **Export named values**
    * CommonJS: `exports.size = 100;`
    * ES Modules: `export const size = 100;`
  * **Current file and folder — Node.js 26**
    * CommonJS: `__filename`, `__dirname`
    * ES Modules: `import.meta.filename`, `import.meta.dirname`
  * **JSON files**
    * CommonJS: `const data = require("./data.json");`
    * ES Modules: `import data from "./data.json" with { type: "json" };`
  * **Top-level `await`**
    * CommonJS: Put `await` inside an `async` function.
    * ES Modules: Use `await` directly in the module.
  * **Project setup**
    * CommonJS: Set `"type": "commonjs"` in `package.json`.
    * ES Modules: Set `"type": "module"` in `package.json`.
