# Production Checklist

## Weekly minimum

- Concept statement updated
- Prototype state documented
- Technical blockers listed
- Next iteration plan defined

## Before mid-review

- Main interaction loop works
- Spatial arrangement is testable
- Input and output mapping is clear
- Setup can run without manual patching

## Before final

- Installation sequence rehearsed
- Safety and cable management checked
- Documentation package complete
- Backup plan prepared
