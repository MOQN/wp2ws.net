# Workflow: Web to Space

## Step 1. Read your source webpage

Define the original interaction model:

- Entry point
- User actions
- State changes
- Visual and sonic feedback

## Step 2. Choose translation strategy

Pick at least one transformation axis:

- Scale
- Input modality
- Material output
- Social context

## Step 3. Prototype quickly

Build a proof-of-interaction before polishing visuals.

## Step 4. Test in context

Run your prototype in the intended space and collect observations.

## Step 5. Iterate toward installation

Refine pacing, robustness, accessibility, and setup time.

Use [Production Checklist](/guide/checklist.md) each week.
