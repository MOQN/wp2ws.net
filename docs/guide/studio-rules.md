# Studio Rules

## Work ethic

- Show progress weekly.
- Test ideas early, not only before deadlines.
- Document decisions, not only outcomes.

## Collaboration

- Define responsibilities in shared projects.
- Keep version control clean and traceable.
- Respect schedule commitments.

## Installation etiquette

- Prioritize audience safety.
- Keep setup and teardown efficient.
- Leave shared spaces cleaner than you found them.
