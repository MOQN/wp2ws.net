# Toolkit

## Suggested software

- p5.js or openFrameworks for interaction sketches
- TouchDesigner for realtime media systems
- Arduino or ESP32 for physical sensing
- Ableton Live or Web Audio for sound response

## Suggested process tools

- Figma or FigJam for interaction mapping
- GitHub Projects for milestone tracking
- Shared drive folder with strict naming convention

## Practical tip

Always maintain a minimal fallback mode that can run if one device fails.
