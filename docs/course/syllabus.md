# Syllabus

## Weekly flow

1. Week 1: Topic framing and case studies
2. Week 2: Concept proposal and interaction mapping
3. Week 3: Prototype v1 and technical risk test
4. Week 4: Mid-review and critique
5. Week 5: Prototype v2 and installation planning
6. Week 6: Final installation and documentation

## Studio rhythm

- Short lecture and references
- Live demo and technical walkthrough
- Work session and desk critiques
- Weekly documentation check

## Evaluation dimensions

- Concept clarity
- Interaction quality
- Spatial translation strength
- Technical execution
- Documentation quality

Check [Milestones](/projects/milestones.md) for concrete submission requirements.
