# Course Overview

Web Page to Web Space is a practice-based studio where students reinterpret a web project as a spatial system.

## Learning goals

- Translate interface logic into physical or spatial interaction.
- Prototype with iterative testing in real environments.
- Build clear documentation for process, decisions, and outcomes.

## Core method

1. Analyze an existing web page or web interaction.
2. Extract its behavior rules (timing, state, feedback, navigation).
3. Re-materialize those rules in space with sensors, projection, sound, objects, or performance.

## Typical outputs

- Interactive installation
- Networked performance setup
- Projection-based spatial interface
- Embodied interaction demo
