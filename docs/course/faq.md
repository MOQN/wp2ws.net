# FAQ

## Do I have to start from scratch?

No. You can begin from your existing web page and transform it into a spatial experience.

## How much coding is required?

Enough to implement and stabilize your interaction concept. The technical stack can vary.

## Can I work in a team?

Yes, if scope and role distribution are clearly documented.

## What counts as documentation?

At minimum:

- Project intent and references
- Process notes with iterations
- Technical setup diagram
- Final photos and short video

Use [Documentation Template](/projects/documentation-template.md).
